# TrollGuard — 巨魔商店版骚扰拦截（iPhone 6s Plus / iOS 15.8 适用）

对标 MIUI 骚扰拦截规则的 iOS 巨魔（TrollStore）应用。内置 **50 万条中国手机号段归属地库**（离线，无需网络）。

---

## 一、功能对照（MIUI 规则页 → iOS 实现）

| MIUI 功能 | iOS 实现 | 状态 |
|---|---|---|
| 拦截所有来电 | — iOS CallKit 只能逐号添加，无法枚举全部号码；替代：系统勿扰/专注模式 | ❌ 平台限制 |
| 拦截陌生号码来电 | 系统「静音未知来电」，App 内一键开关（巨魔权限直写系统偏好，失败自动跳转设置页） | ✅ |
| 拦截未知号码与空号码来电 | 同上（系统功能一并覆盖，通讯录=自动白名单） | ✅ |
| 拦截海外来电 | 同上（海外陌生号全部静音）；精确拦截可加国际区号前缀（短信生效） | ✅ 近似 |
| 骚扰电话/疑似诈骗/高风险/广告推销/房产中介/保险理财 | 6 个分类号码库：批量导入号码清单（CSV/粘贴/剪贴板），开关即用 | ✅（需自备号码清单） |
| 按归属地拦截（293个） | 归属地库已内置：省市归属地查询、号段统计；**按省拦截来电 iOS 物理不可行**（拦一个省要添加上百亿条）；短信不受此限，加地区码即可按地区拦短信 | ⚠️ 部分 |
| 按开头号码拦截 | 来电：前缀 ≥10 位生效；短信：任意长度生效 | ✅ |
| 重复来电不拦截 | — iOS 无对应机制 | ❌ |
| 名单管理 | 黑名单（CallKit 拦截）+ 白名单（通讯录自动放行） | ✅ |
| 来电/短信关键词与号码过滤 | CallKit + ILMessageFilter，命中短信进「过滤信息」 | ✅ |

**为什么「按归属地拦截来电」做不到**：安卓系统能逐条判断来电；iOS 的 CallKit 黑名单是"逐个添加具体号码"，拦截"北京"全部号码 = 上百亿条目，无解。这是苹果平台级限制，与巨魔权限无关。App 内已内置归属地库用于查询和号段管理，并把最实用的等效方案（静音未知来电 + 分类号码库 + 短信地区拦截）做全。

## 一之二、内置规则库与号码库源（已内置，装完即可用）

App 内「内置规则库」默认关，打开即生效（作用在短信层，因为短信过滤对比的是发件人字符串，任意前缀都有效）：

| 内置库 | 内容 | 说明 |
|---|---|---|
| 1069 营销短信端口 | 1069 | 商业营销短信主通道，少量验证码也走此通道 |
| 全部 106 短信端口 | 106 | 过滤更彻底，会误伤验证码 |
| 企业外呼 400/95/96 | 400、95、96 | 银行/保险/催收外呼高发 |
| 虚拟运营商号段 | 170/171/162/165/167/192 | 工信部公开分配的移动转售号段，推销高发 |
| 国际区号 | 1/44/852/853/886/81/82/65/60/66/84/91 | 境外号码短信拦截 |
| 拦截境外短信 | — | 发件人非 +86 一律归入过滤信息 |

**号码库源（订阅导入）**：中文骚扰号码库没有官方可下载的公开源（12321 不提供导出、运营商库不公开、GitHub 上没有可用的中国号码清单）。因此 App 提供订阅机制——填任意公开库 URL 一键拉取，自动识别纯文本 / CSV / JSON，支持按国家码过滤后导入分类库。内置三个推荐源（MalwareWorld 全球垃圾电话库约 9 万条、OpenCallShield、CallShield）。国内号码建议从手机标记平台导出 CSV，走「粘贴导入」。

> 我实测过 MalwareWorld 的 `suspiciousPhones.txt`：9.1 万条里中国号码只有 2 条（都是北美 NANPA 数据），所以没有把它硬编码进 App 当作"中国骚扰库"——那是误导。宁可用真实的号段规则 + 可订阅的机制。


## 二、没有 Mac 也能拿到 IPA：GitHub 免费云编译

iOS 应用必须在 macOS + Xcode 下编译。用 GitHub 的免费 macOS 云机器，全程网页操作约 10 分钟：

1. 注册 https://github.com → 右上 `+` → **New repository** → 名字 `trollguard` → **Public** → 创建
2. 点 **uploading an existing file**，把本工程文件夹内容（含 `.github`）拖进去 → **Commit changes**
   （Windows 需在资源管理器打开「查看 → 隐藏的项目」才能看到 `.github`；拖不进去就 Add file → Upload files 上传 `.github/workflows/build-tipa.yml`）
3. **Actions** 标签 → 左侧 **build-tipa** → **Run workflow** → 等绿勾（3~6 分钟）
4. 点进记录 → 底部 **Artifacts** → 下载 **TrollGuard-tipa** → 解压得 `TrollGuard.tipa`
5. 传到 iPhone → 巨魔商店打开 → Install

有 Mac 则：`brew install xcodegen ldid && ./build_ipa.sh`

## 三、安装与启用

1. iPhone 6s Plus（A9）+ iOS 15.8 ✅ 巨魔支持（15.5–16.6.1；装巨魔走 TrollHelper，见 ios.cfw.guide）
2. 安装后开两个系统开关：
   - 设置 → 电话 → 来电阻止与身份识别 → 勾选「骚扰拦截」
   - 设置 → 信息 → 未知与过滤信息 → 启用「骚扰拦截」
3. App 内：导入号码清单 / 加前缀 / 加关键词 → 点「更新拦截数据库」
4. 「拦截陌生号码来电」开关：尝试直写系统偏好，失败则点「去系统设置开启」手动开

## 四、工程结构

```
TrollGuard/
├── project.yml                       # XcodeGen 工程定义
├── build_ipa.sh                      # 编译 + ldid 注入 + 打包 .tipa
├── .github/workflows/build-tipa.yml  # GitHub 云编译工作流
├── Entitlements/                     # 巨魔专用 entitlements
├── App/                              # 主 App：拦截规则页（对照 MIUI）+ 归属地查询 + 号码库
│   ├── ContentView.swift             # 主规则页 / 查询页 / 说明页
│   ├── Views.swift                   # 前缀 / 归属地 / 号码库 / 关键词 子页面
│   └── SettingsHelper.swift          # 静音未知来电直写 + 设置页跳转
├── Shared/
│   ├── RuleStore.swift               # App Group 共享规则（黑名单/分类库/前缀/关键词）
│   ├── PhoneLocation.swift           # phone.dat 解析器（二分查找 + 省市统计）
│   └── Resources/phone.dat           # 中国号段库 499,527 条（ls0f/phone，离线内置）
├── CallDirectoryExtension/           # CallKit 来电拦截（号码库 + 有效前缀，升序注入）
└── MessageFilterExtension/           # 短信过滤（号码/前缀/关键词三重匹配）
```
